# dead_data
Статические исследования на исторических датасетах

## Структура

- [SQL](./sql) — SQL-анализ датасета Superstore (запросы, визуализация, бизнес-выводы)
- [SQL-продуктовые метрики](./sql-продуктовые%20метрики) — Расчет продуктовых метрик (Retention, LTV, ARPU, ARPPU, ROI) на данных интернет-магазина
- [EDA](./EDA) — Исследовательский анализ данных о влиянии кофе на здоровье
