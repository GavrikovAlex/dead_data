# SQL + продуктовые метрики интернет-магазина

## Описание проекта

Анализ транзакционных данных интернет-магазина за период с 01.12.2010 по 09.12.2011. Проект выполнен в Google Colab с использованием SQLite и Python. Данные содержат информацию о покупках клиентов из Великобритании.

## Цель проекта

Практика расчета ключевых продуктовых метрик на основе реальных данных интернет-магазина с использованием SQL и Python.

## Данные

**Источник:** Online Retail Dataset (UCI Machine Learning Repository)

**Описание полей:**

| Поле | Описание |
|------|----------|
| InvoiceNo | 6-значный идентификатор транзакции. Если код начинается с 'c' — отмена заказа |
| StockCode | 5-значный идентификатор товара |
| Description | Наименование товара |
| Quantity | Количество единиц товара в транзакции |
| InvoiceDate | Дата и время транзакции |
| UnitPrice | Цена за единицу товара (в фунтах стерлингов) |
| CustomerID | 5-значный идентификатор клиента |
| Country | Страна проживания клиента |

## Инструменты

- **SQL (SQLite)** — расчет метрик
- **Python (Pandas, Matplotlib, Seaborn)** — предобработка, визуализация, выводы
- **Google Colab** — среда выполнения
