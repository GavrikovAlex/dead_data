# EDA - Исследовательский анализ данных о влиянии кофе на здоровье

## Описание проекта
Анализ синтетического датасета о потреблении кофе и показателях здоровья (сон, пульс, стресс, ИМТ). Проект выполнен в Google Colab с использованием Python. Данные содержат 10 000 записей из 20 стран.

## Цель проекта
Выявление статистически значимых взаимосвязей между уровнем потребления кофе и ключевыми метриками здоровья.

## Данные
Источник: синтетический датасет

Основные поля:

| Поле | Описание |
|:---|:---|
| Coffee_Intake | Ежедневное потребление кофе (чашек) |
| Sleep_Hours | Средняя продолжительность сна (часы) |
| Heart_Rate | Частота сердечных сокращений (уд/мин) |
| Stress_Level | Уровень стресса (Low/Medium/High) |
| BMI | Индекс массы тела |
| Age | Возраст |
| Gender | Пол |
| Country | Страна |

## Инструменты
- **Python (Pandas, NumPy)** — обработка данных
- **Matplotlib, Seaborn** — визуализация
- **SciPy (stats)** — статистические тесты (Pearson, ANOVA, t-test)
- **Google Colab** — среда выполнения

## Ключевые результаты
- **Сон:** отрицательная связь с потреблением кофе (r = -0.189, p < 0.001)
- **Пульс:** слабая положительная связь (r = 0.058, p < 0.001)
- **Стресс:** положительная связь (r = 0.150, p < 0.001)
- **ИМТ:** статистически значимой связи не обнаружено (p > 0.05)
