# SQL: исследования базы Superstore

Статические исследования исторического датасета **Sample – Superstore** средствами SQL (SQLite).

## Содержимое

- `SQLite_superstore_dead.ipynb` — Jupyter notebook с SQL-запросами, EDA и визуализацией
- `Sample - Superstore.csv` — исходный датасет
- `superstore.db` — база данных SQLite
- `requirements.txt` — зависимости для запуска ноутбука

## Запуск

```bash
pip install -r requirements.txt
jupyter notebook SQLite_superstore_dead.ipynb
```
